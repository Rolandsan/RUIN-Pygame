# RUIN — Pygame Shooting Game

RUIN is a DOOM-inspired arcade shooting game developed using Python and Pygame as part of my university multimedia programming coursework in 2024.

Inspired by the classic Duck Hunt game (1984), RUIN challenges players to shoot moving demon targets while earning points within a limited time.

## Features

- Three playable levels with different backgrounds
- Four demon enemy types
- Mouse-based shooting mechanics
- Shooting animation and hit detection
- Score tracking (10, 20, 30, and 40 points)
- Countdown timer
- Main menu and replay functionality

## LIBRARY

- Python
- Pygame

## Installation

Create a Python virtual environment and install the dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python RUIN.py
```

## Controls

- **Mouse:** Aim
- **Left-click:** Shoot
- **Start:** Begin the game
- **Replay:** Return to the beginning after game over

Originally created in January 2024 for a university multimedia programming assignment. This repository contains a reconstructed version of the original project.
